# 侧边自由对话 (Freedom chat)

**在每个主对话的右侧栏，开一个只聊天、不干活的独立面板。**

主对话在跑任务，你想顺手问一句、推演一个思路、或者让另一个模型换个角度看看同一个问题——但又不想把这段闲聊塞进主对话的上下文，也不想让它有机会动你的文件。

这个插件就是干这个的：一个**与主对话隔离**的对话窗口。它有自己的模型、自己的历史、自己的开关，默认什么都碰不到。

## 它和「侧边对话(beta)」有什么不同

| | 侧边自由对话 | 侧边对话(beta) |
| --- | --- | --- |
| 上下文 | 空白开始，**不继承**主对话 | 继承主对话全部历史 |
| 工具 | **零本地执行**，宿主层硬拦截 | 沿用主对话预设，可执行工具 |
| 模型 | 每个面板独立选择，默认跟随主对话 | 继承主对话 |
| 清空 | 删除这条侧对话及其记录 | 新建线程 |
| 归档 | 随主对话一起删除 | 归档被禁用 |

两者可以同时存在，互不影响。

## 功能

- **独立面板**：右侧栏新增一个标签页，每个主对话一个，打开方式与官方侧边栏标签一致。
- **空白上下文**：从第一条消息开始，看不到主对话的历史，也不会污染主对话的上下文。
- **零本地执行**：侧边会话里没有任何内置工具；任何工具调用都会被宿主在执行前拒绝，模型会如实告诉你它没有权限。
- **自选模型与推理强度**：输入区上方的模型胶囊打开卡片式选择器，按来源分组；默认继承主对话当前模型，改动只作用于这条侧对话，不会改掉你的全局默认。
- **图片输入**：左下角回形针选择，或直接把图片粘贴进输入框。
- **按需联网**：默认关闭；打开后只放行 `web_search` / `web_fetch` / `research` 三个工具，其余一概拒绝。
- **双向读取，都要你点头**：
  - 「读从对话」开关：打开后，主对话才会获得读取这个面板的能力，而且只在你本轮明确说「读一下侧边对话」时才放行；其它情况一律拒绝并提示先问你。
  - 「读主对话」三态：允许 / 询问 / 不允许。选「询问」时，主对话内容被读取前，面板底部会出现一条确认，2 分钟内不确认就按拒绝处理。
- **关掉即失效**：面板一关，主对话里的读取能力立刻消失——没打开面板的主对话，完全不受这个插件影响。
- **清空即删除**：点清空会删掉这条侧对话和它的记录，下一条消息再开一条新的，不会在后台留一堆子会话。
- **跟随生命周期**：重启 DSH 会冷恢复你的聊天记录；主对话归档，侧对话随之删除并显示墓碑（取消归档后可以新建）；主对话被删除，它也会被清理。
- **一对一**：一个主对话只允许一条侧对话，多窗口也不会重复创建。

## 怎么用

1. 在任意主对话右侧栏点「💬 侧边自由对话」。
2. 直接发消息——第一条消息才会真正创建会话，面板空着不会产生垃圾。
3. 需要换模型：点模型胶囊，选模型（当前模型若是推理模型，下面会给出强度选项）。
4. 需要看图：粘贴或点回形针。
5. 想让主对话读这边：打开「读从对话」，然后回主对话说「读一下侧边对话」。
6. 想让这边读主对话：把「读主对话」切到「允许」（或「询问」，每次确认）。
7. 想清空：点标题右侧的垃圾桶，这条侧对话会被删除。

## 安全边界（重要）

- 侧边会话的工具白名单是**空的**；宿主在 `tools/pre-execute` 上有一道硬闸门，即使模型绕过可见性去调用，也会被拒绝。
- 「主对话读从对话」的能力是**按需挂载**的：只有面板打开且开关打开时才存在；关闭面板即卸载。
- 读取范围固定为主对话最近 20 条**用户与助手正文**，工具调用与工具结果不会被带过去。
- 联网工具默认关闭，打开后也只放行上述三个。

## 数据与隐私

- 注册表：`~/.dsh/freedomchat/threads.json`（只记录主会话 → 侧会话的映射、开关、模型）。
- 会话记录：与 DSH 其它会话一样存放在 `~/.dsh/sessions/<项目段>/<会话 id>/`。
- 无遥测、无外部请求；只有你显式打开的联网工具会访问网络。

## 兼容与安装

- 需要 DSH `>= 0.2.2-rc.3`、Node `>= 22`；桌面版与网页版都可。
- 从 Release 安装：`dsh plugin --profile desktop add <release 里的 .tgz 地址>`。
- 本地目录安装：`dsh plugin --profile desktop add link:<插件目录>`。
- 安装后重启 DSH 生效；之后只改客户端代码刷新页面即可。

## 已知限制

- 面板关闭时，主对话工具列表里就**没有**读取工具了；如果你在关掉面板后才让它读，模型会看到 `unknown tool`。这是「面板关＝零影响」的代价。
- 归档检测是 1 秒轮询：归档后 1 秒内又取消归档的极端情况抓不到。
- `origin: subagent` 的会话不会出现在 DSH 会话列表里（宿主既有行为），所以侧对话只能在面板里看。
